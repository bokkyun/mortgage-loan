문의하기 (Contact)

Mortgage Loan Lab에 대한 문의·제안·오탈자 신고는 아래 채널로 받고 있습니다. 회신에는 평일 기준 1~3 영업일 정도 소요될 수 있으며, 명절·연휴 기간에는 더 지연될 수 있는 점 양해 부탁드립니다.

홈 연락 채널 어떤 문의가 가능한가요 이메일 템플릿 개인정보 처리방침

1. 연락 채널

  • 이메일 : mortgageloanlab@gmail.com — 가장 정확하게 회신이 가능한 채널입니다. 스팸 방지를 위해 제목에 [문의], [오류], [제안] 등 구분 태그를 붙여주시면 감사하겠습니다.
  • GitHub 이슈 (공개) : github.com/bokkyun/mortgage-loan/issues — 계산 결과 오류·UI 버그·요청 기능 등 공개 가능한 내용은 GitHub 이슈로 올리시면 버전 기록과 함께 관리됩니다.
  • 콘텐츠 수정 요청 — 가이드 글·필요서류 안내에 오탈자나 잘못된 정보가 있을 경우, 해당 페이지 URL과 함께 알려주시면 빠르게 검토합니다.

2. 어떤 문의가 가능한가요

  • 계산 오류 제보 — 특정 입력값에서 결과가 공식 안내와 크게 다르다고 판단될 때. 가능하면 입력값·브라우저·예상 결과·실제 출력값을 모두 알려주시면 재현이 빠릅니다.
  • 신규 계산기·가이드 요청 — 추가되었으면 하는 주택자금·대출 관련 주제를 알려주시면 우선순위를 검토합니다.
  • 콘텐츠 오탈자·링크 오류 — 어느 페이지의 어느 문장인지 명시해 주세요.
  • 접근성·사용성 피드백 — 모바일 레이아웃, 스크린 리더 호환, 색 대비 등.
  • 개인정보·광고 관련 문의 — 쿠키 설정·개인정보 처리방침 관련 질문.
  • 협업·제휴 — 콘텐츠 공동 작성, 자료 제공, 사이트 번역 등 제안.

3. 회신이 어려운 문의

본 사이트는 참고용 계산기를 제공하는 개인 운영 프로젝트이며, 다음과 같은 요청에는 회신이 어렵거나 제공이 불가합니다. 양해 부탁드립니다.

  • 개별 심사 결과 예측 또는 대출 가능 여부 단정
  • 특정 금융기관·지점의 내부 기준 문의
  • 법률·세무·투자 자문
  • 개인 신용·소득·자산 정보의 분석 대행

위 유형의 질문은 관할 금융기관, 한국주택금융공사(HF), 주택도시보증공사(HUG), 한국신용정보원, 해당 분야 자격 전문가에게 문의하시는 것이 가장 정확합니다.
